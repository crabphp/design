Crab design system█

Tokens, components and charts for CrabPHP applications. It looks like the Crab site: one typeface, one size, a dark page, amber for what you can act on. Everything here is plain HTML and CSS; copy the markup under any example.

<link rel="stylesheet" href="css/crab.css">

Colour

Every colour is a token in tokens.css. White carries text at four strengths, amber marks what you can act on, and four status colours always sit beside a word.

Type and space

One family, one size, one line height, two weights. Vertical space is counted in lines and horizontal space in characters, so everything sits on the same grid.

TokenValueUse
--fontThe only typeface
--sizeThe only text size; 14px on phones
--lhOne line: the unit of vertical space
--halfhalf a lineCell padding, gaps inside a component
--gapHorizontal gap between related things
--gutterBetween columns
--measureReading column
--wideApplication content
--navNavigation column
--control1.25 lines; 36px on touch screensHeight of an input or solid button
--touchTap area of a text button on touch screens

Text elements

Plain HTML needs no classes. Headings are uppercase and bold at body size, marked like Markdown.

Buttons

A button is bracketed amber text. Use one .solid button for the main action of a view, .quiet for secondary actions and .danger for destructive ones.

Segmented

A few choices where one is on. Each button carries aria-pressed.

Menu

A native popover: it opens under its button, closes on Escape or a click outside, and needs no script.

Inputs

A .field is a label, a control and an optional help line. Controls are square, a line and a quarter tall, with a border strong enough to see.

Chart colour

Seven series colours in a fixed order, chosen so neighbours stay apart for colour-blind readers. Assign them in order and never reuse one for a different series. A one-hue ramp shows magnitude.

Line

Change over time. Hover or use the arrow keys to read a day; every chart also offers its numbers as a table.

Columns

Amounts per period. Bars are thin and square, and stacked parts are separated by a gap, not an outline.

Toasts

A short confirmation that leaves on its own. Put a .toasts region at the end of the page and add each message to it.

<div class="toasts" role="region" aria-label="Notifications" aria-live="polite">
  <div class="toast ok">Message sent. <button type="button" class="quiet">Dismiss</button></div>
</div>
